# Fish Photobooth

A fish-themed photobooth app — take photos, add stickers, and download your photo strip!

## Try It Online

**[Open Fish Photobooth](https://photobooth-two-phi.vercel.app)** — works on desktop and mobile browsers.

## Download & Run (Mac)

> Requires macOS with Apple Silicon (M1/M2/M3)

[Download Photobooth v1.0.0 (.dmg)](https://github.com/Tanvir-Rafi03/Photobooth/releases/download/v1.0.0/Photobooth-1.0.0-arm64.dmg)

1. Download the `.dmg` file above
2. Open it and drag **Photobooth** into your Applications folder
3. Launch the app from Applications

> If macOS says the app is from an unidentified developer, go to **System Settings → Privacy & Security** and click **Open Anyway**

## Run from Source

Requires [Node.js](https://nodejs.org) installed.

```bash
git clone https://github.com/Tanvir-Rafi03/Photobooth.git
cd Photobooth
npm install
npm start
```
